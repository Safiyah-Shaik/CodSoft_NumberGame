# CodSoft Task 1 - Number Game

A console-based Number Guessing Game developed using Java.

## Features
- Generates a random number between 1 and 100.
- Provides higher and lower hints.
- Limits each round to 7 valid guesses.
- Supports multiple rounds.
- Calculates scores based on attempts.
- Displays total rounds won and final score.

## Technologies Used
- Java 25
- Java Scanner
- Java Random

## How to Run

Compile the program:

```bash
javac src/main/java/NumberGame.java
